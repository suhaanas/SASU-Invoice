# Invoxa 🧾✨

![Invoxa Preview](index.html) <!-- Note: Add a real screenshot here later! -->

**Invoxa** is a modern, privacy-first, client-side invoice generator built to run entirely in your browser. It allows freelancers and small businesses to quickly create, preview, and export stunning professional invoices without needing an account or a subscription.

## 🚀 Features

*   **Live Preview Interface:** A beautiful 3-column layout where every keystroke instantly updates a perfectly formatted invoice sheet.
*   **AI Invoice Assistant:**
    *   **Magic Wand API:** Automatically expand short, shorthand descriptions (e.g. "built site") into professional billing language.
    *   **AI Writer:** Generate context-aware payment notes and polite thank-you messages with one click.
*   **Extensive Customization:**
    *   **6 Color Themes:** Match your invoice exactly to your brand's color palette.
    *   **8 Currencies:** Support for USD, EUR, GBP, INR, JPY, AUD, CAD, and LKR.
    *   **Logo Shaper:** Choose how your uploaded logo looks (Square, Rounded, or a modern Circle avatar).
*   **Privacy First:** Everything runs locally using JavaScript. No data is stored on our servers.
*   **Export Anywhere:** Download your finished invoice as a high-quality **PDF**, a 2x retina **PNG** image, or print directly to A4/Letter paper format.

## 🛠️ Tech Stack

Invoxa is built using a lightweight, dependency-free frontend stack to ensure lightning-fast load times:
*   **HTML5 & CSS3:** Semantic structure with a modern, customized styling system.
*   **Vanilla JavaScript:** Core logic, state management, and DOM manipulation.
*   **jsPDF & jsPDF-AutoTable:** For precise, professional PDF generation (`cdnjs`).
*   **html2canvas:** For high-resolution PNG image exporting (`cdnjs`).

## 💻 Getting Started

There's no build step required. Just open the files!

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/suhaAnas/SASU-Invoice.git
    cd SASU-Invoice
    ```
2.  **Open the app:**
    Simply open the `index.html` file in any modern web browser to view the landing page, or open `app.html` to jump straight into the generator tool.
